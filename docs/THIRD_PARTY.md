# Third-party components and content

The application resolves dependencies through Maven; native browser binaries are downloaded by jcefmaven when needed rather than committed to this repository.

- [OpenJFX](https://openjfx.io/) supplies JavaFX controls, FXML and web support.
- [jcefmaven](https://github.com/jcefmaven/jcefmaven) supplies the Java Chromium Embedded Framework integration and runtime setup.
- [jsoup](https://jsoup.org/) parses HTML for experimental price discovery.
- [JUnit](https://junit.org/) is used for the public repository's automated tests.

Consult each project's own licence and the resolved dependency/native distributions for applicable notices, including transitive components. This file does not replace those licences or grant rights to their content.
